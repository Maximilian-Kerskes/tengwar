# Current Lexicographical Rules and Constraints for the Shell

## Currently supported tokens

- 'EOF' - End of File
- 'WORD' - Any string of characters that is not whitespace
- 'NEWLINE' - Newline
- 'SEMICOLON' - Semicolon
- 'REDIRECT_IN' - '<'
- 'REDIRECT_OUT' - '>'
- 'REDIRECT_APPEND' - '>>'
- 'PIPE' - '|'
